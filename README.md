# InkFlow 墨流 · 数学答案转手写体

把数学 / 学科答案文档一键转成逼真手写体。**纯浏览器本地处理**：不上传、不存储、刷新即清空。

---

## 快速开始

**方式一（推荐）**：直接双击 `index.html`，用 Chrome / Edge 打开即可。

**方式二**：把整个目录作为静态站点根目录，用任意 http 服务器访问。

> 首次打开会加载约 12MB 字体与公式引擎，全部来自本地文件，**不访问任何网络**。

---

## 三步出结果

1. 左侧粘贴内容（支持 Markdown 标题、列表、代码块）；
2. 公式用 `$...$`（行内）或 `$$...$$`（独立成行）；
3. 右侧实时预览 → 「导出 PNG / PDF」。

纯静态站点，**可直接部署到 Vercel / Netlify / Cloudflare Pages / GitHub Pages**：无后端、无构建步骤、无环境变量。

```bash

vercel --prod
```

完整步骤（含 Git 导入、拖拽上传、自检清单）见 [`DEPLOY.md`](DEPLOY.md)。

> 部署与本地双击 `index.html` 互不冲突：项目不含 ES Module 与运行时 fetch，两种方式都能跑。

## 文字样式

和 Word 一样，可以单独调整正文的呈现方式（不影响公式的正确性）：

| 控件 | 说明 |
|---|---|
| **B** 加粗 | 字体本身有粗体字重时用真粗体；没有时自动用描边加粗（中文手写体多属此类） |
| **I** 斜体 | 使用字体的斜体变体 |
| **U** 下划线 | 沿文字底部画一条带轻微抖动的线，更接近手写 |
| **字色** | 正文颜色，可与墨水颜色分开设置 |
| **缩放** | 0.70×–1.60×，等价于 Word 的字号缩放 |

## 生成方式

默认是**自动生成**：改动任意参数（字体、档位、字号、纸张…）后会自动重绘，无需手动操作。

如果内容较长、希望改完参数再统一生成，可以：

1. 取消勾选预览区右上角的「**自动**」；
2. 之后每次改动参数，只会在「**生成手写稿**」按钮上出现**橙色圆点**提示；
3. 点该按钮（或按 `Ctrl/⌘ + Enter`）才会真正重新生成。

## 隐私说明

- **没有服务器**：全部计算在浏览器内完成；
- **不上传**：不发起任何 fetch / XHR / Beacon / WebSocket 请求（有自动化测试断言）；
- **不存储**：不写 localStorage / sessionStorage / cookie（有自动化测试断言）；
- **刷新即清空**：所有内容仅存在于内存中；
- **自定义字体也只在本机读取**，不经过网络。

## 公式"手写化"是怎么做的

数学公式里的**数字和符号（∠ △ ≅ ∵ ∴ √ ∫ ∑ π ° × 分数）也会变成手写体**，
不只是正文。做法是「**MathJax 算位置，手写字体画字形**」：

1. MathJax 解析 LaTeX，算出每个字形的**精确坐标、字号、基线**（保证排版与含义 100% 正确）；
2. 遍历 SVG 的 `<g data-mml-node>` 嵌套，累乘 transform 矩阵，得到每个字形的绝对位置；
3. 逐字符挑字体：
   - 先试**当前正文手写体**；
   - 再试 **Zen Kurenaido**（实测数学符号覆盖 66/66，是最可靠的兜底）；
   - 个别符号所有手写体都没有（如 `≅`），就用**两个手写字符拼出来**（`∼` + `=`）；
   - 万一仍然拼不出，**保留 MathJax 原字形**——宁可不像手写，也绝不丢内容；
4. 分数线 / 根号线 / 表格线用**带轻微起伏的曲线**重画，像手画的横线；
5. 再叠加轻微抖动（字被写歪、大小不一）。

> 关键前提：`Zen Kurenaido` 这款日文手写体对数学符号的覆盖率是 **66/66**，
> 而多数中文字体只有约 30/66（缺 ∠ △ ≅ ∵ ∴ √ ∫ ∑ π…）。
> 所以它被放在字体链第二位，专门负责符号兜底。

## 已知限制

1. **公式是"印刷体 + 手写扭曲"**，不是真人手写笔迹——这是当前开源方案下"公式正确性"与"手写感"的最佳平衡；
2. 单个公式若宽度超过正文可用宽度，会**自动等比缩小**以完整容纳（不再溢出或裁切）；
3. 中文字体文件较大（约 5–6 MB / 款），首次加载需数秒；
4. 导出 PDF 采用高分辨率位图嵌入，文本不可选中（手写体场景下这是预期行为）；
5. 自定义字体若本身不含中文字形，中文会回退到系统字体显示；
6. **图片 OCR 需要 http(s) 环境**：浏览器禁止 `file://` 页面创建 Worker，因此本地双击打开时"识别图片"按钮会置灰；线上版本（Vercel 等）正常可用。
