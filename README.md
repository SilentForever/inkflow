# InkFlow 墨流 · 数学答案转手写体

把数学 / 学科答案文档一键转成逼真手写体。**纯浏览器本地处理**：不上传、不存储、刷新即清空。

---

## 快速开始

**方式一（推荐）**：直接双击 `index.html`，用 Chrome / Edge 打开即可。

**方式二**：把整个目录作为静态站点根目录，用任意 http 服务器访问。

> **加载策略**：首次打开只需加载**默认中英各一款字体（约 1.4MB）+ 公式引擎**即可出首屏，其余字体随后在后台补齐；PDF / Word / 图片识别等重型组件改为**按需加载**（用到才加载）。字体已用 **WOFF2** 压缩（整包 47MB → 21MB）。全部来自本地文件，**不访问任何网络**。

---

## 三步出结果

1. 左侧「**导入**」页签拖入或选择文件（PDF / Word / 图片 / Markdown / TXT），也可切到「**编辑**」页签直接粘贴 Markdown；
2. 公式用 `$...$`（行内）或 `$$...$$`（独立成行）；
3. 右侧实时预览 → 「导出 PNG / PDF」。

## 左栏：一体化导入面板 + WPS 式工具栏

左栏顶部是一条仿 **WPS** 的工具栏（对应「开始」选项卡），分两行、分组排布，窄栏也不会横向溢出：

| 行 | 内容 |
|---|---|
| 第 1 行 | **中文字体**、**英文字体**（两个下拉，等宽并排）、**字号**（数字框 + px，12–96 px） |
| 第 2 行 | **B / I / U**（按钮）· 分隔 · **字色** · 分隔 · **缩放** 滑块 |
| 工具栏下方 | **导入**（默认）↔ **编辑** 两个页签 |

- **默认停在「导入」页**：**整块区域就是一体化导入面板**——一个虚线卡片，**点它任意位置即弹出文件选择（支持多选）**，**把文件拖到整块左栏任意位置也能导入**，卡片下方另有两个轻量入口「粘贴文本 / 识别图片」；
- **单篇 / 批量不再需要手动切换**（切换按钮已移除）：**一次只导 1 个文件**（或在「编辑」页直接写）就是单篇，导入后**自动切到「编辑」页**开始渲染；**一次导入 ≥2 个文件**就是批量，队列**就地展开在导入页**，点「全部转写」逐个排队生成；
- 「**编辑**」页是 Markdown / LaTeX 文本框，专门用于单篇精修；点它即**清空上一批队列**、回到单篇；
- 原来的「只读预览」视图、三个并排导入按钮、以及冗余的「单篇 / 批量」切换按钮均已移除（导入面板 + 文件数即可完成全部操作）。

## 生成方式

默认是**自动生成**：改动任意参数（字体、档位、字号、纸张…）后会自动重绘，无需手动操作。

如果内容较长、希望改完参数再统一生成，可以：

1. 取消勾选预览区右上角的「**自动**」；
2. 之后每次改动参数，只会在「**生成手写稿**」按钮上出现**橙色圆点**提示；
3. 点该按钮（或按 `Ctrl/⌘ + Enter`）才会真正重新生成。

## 隐私说明

- **没有服务器**：全部计算在浏览器内完成；
- **不上传**：不发起任何 fetch / XHR / Beacon / WebSocket 请求（有自动化测试断言）；

## 公式"手写化"是怎么做的

公式里的**数字和符号（∠ △ ≅ ∵ ∴ √ ∫ ∑ π ° × 分数）也会变成手写体**：

1. MathJax 解析 LaTeX 得到矢量 SVG（保证排版与含义 100% 正确）；
2. **让浏览器真实布局一遍**，用 `getBoundingClientRect()` 读出每个字形的**真实像素坐标与尺寸**；
3. 用**手写字体**在 **canvas** 上重画字形（字号按字形实测高度反推）；
4. 分数线 / 根号线 / 表格线重画成**带轻微起伏的曲线**；
5. 叠加抖动，幅度受「公式手写度」滑杆控制。

> **为什么必须画在 canvas 上？**
> SVG 以 `<img>` 载入时处于**隔离环境，读不到页面的 Web 字体**（浏览器会静默换成系统字体），
> 所以不能把 `<text>` 放进 SVG——那样数学符号永远是系统字形、尺寸也对不上。
> 正确做法：SVG 只用来**取位置**，字形一律在 canvas 上绘制。

**字体链**（逐字符挑选，先命中先用）：

| 顺序 | 字体 | 作用 |
|---|---|---|
| 1 | 当前正文手写体 | 保持一致观感 |
| 2 | **Zen Kurenaido** | 圆珠笔手写，符号覆盖好，专职兜底 |
| 3 | Klee One / Yomogi / 刘建毛草 / 马善政 / 龙藏 / 志莽行书 | 补充 |

**缺失符号的三级处理**：

| 级别 | 做法 | 例子 |
|---|---|---|
| 1 | 换字体 | ∠ △ ∵ ∴ √ ∫ ∑ π → Zen Kurenaido |
| 2 | **组合字形**（两个手写字符拼合） | ≅ → `∼` + `=` |
| 3 | 保留 MathJax 原字形（作为一张图片叠加） | 极少数生僻符号 |

第 3 级是**安全网**：宁可字形不像手写，也绝不丢内容或画错。

## 批量队列（多篇一次导入）

**一次导入多个文件**（MD / TXT / PDF / DOCX / 图片）即自动进入批量：队列**就地展开在「导入」页**，无需切换任何模式。

```
导入页：  [ 一体化导入卡片 ]
          ──────────────────────────────
          批量队列 · 已导入 3 篇   [ 全部转写 ] [ 停止 ]  全选  [ 导出选中 ] [ 清空 ]
```

| 状态 | 徽标 | 含义 |
|---|---|---|
| 待转写 | ○ 待转写 | 已解析出 Markdown，等待渲染 |
| 转写中 | ⟳ 转写中 | 正在渲染 |
| 已完成 | ✓ 已完成 n 页 | 结果已缓存，点一下即可查看 |
| 失败 | ✕ 原因 | 例如「未识别到内容」 |

- 队列顶部显示**已导入 N 篇**；点「全部转写」按列表顺序**逐个渲染**（带进度条），也可点某篇**单独预览**；
- **结果缓存**：转写过的文档保存在内存里，不刷新就能逐个点开查看；参数没变时点击**瞬时切换**。
- **批量导出**：勾选若干篇 → 合并导出为一个 PDF（按列表顺序）。
- 点「编辑」页签即**清空队列**、回到单篇编辑器。
- 刷新页面即全部清空，**不写入任何本地存储**。

## 已知限制

1. **公式是"印刷体 + 手写扭曲"**，不是真人手写笔迹——这是当前开源方案下"公式正确性"与"手写感"的最佳平衡；
2. 单个公式若宽度超过正文可用宽度，会**自动等比缩小**以完整容纳（不再溢出或裁切）；
3. 中文字体文件较大（WOFF2 后约 2–3 MB / 款），已改为**默认字体优先 + 后台补齐**：首屏仅需约 1.4MB，其余字体随后加载；
4. 导出 PDF 采用高分辨率位图嵌入，文本不可选中（手写体场景下这是预期行为）；
5. 自定义字体若本身不含中文字形，中文会回退到系统字体显示；
6. **图片 OCR 需要 http(s) 环境**：浏览器禁止 `file://` 页面创建 Worker，因此本地双击打开时"识别图片"按钮会置灰；线上版本（Vercel 等）正常可用。
