# InkFlow 墨流 · 数学答案转手写体

把数学 / 学科答案文档一键转成逼真手写体。**纯浏览器本地处理**：不上传、不存储、刷新即清空。

---

## 快速开始

**方式一（推荐）**：直接双击 `index.html`，用 Chrome / Edge 打开即可。

**方式二**：把整个目录作为静态站点根目录，用任意 http 服务器访问。

> 首次打开会加载约 12MB 字体与公式引擎，全部来自本地文件，**不访问任何网络**。

---

## 三步出结果

1. 左侧粘贴内容（支持 Markdown 标题、列表、代码块）；
2. 公式用 `$...$`（行内）或 `$$...$$`（独立成行）；
3. 右侧实时预览 → 「导出 PNG / PDF」。

## 部署

纯静态站点，**可直接部署到 Vercel / Netlify / Cloudflare Pages / GitHub Pages**：无后端、无构建步骤、无环境变量。

```bash
# 最快：安装 CLI 后一键发布
npm i -g vercel
vercel --prod
```

完整步骤（含 Git 导入、拖拽上传、自检清单）见 [`DEPLOY.md`](DEPLOY.md)。

> 部署与本地双击 `index.html` 互不冲突：项目不含 ES Module 与运行时 fetch，两种方式都能跑。

## 隐私说明

- **没有服务器**：全部计算在浏览器内完成；
- **不上传**：不发起任何 fetch / XHR / Beacon / WebSocket 请求（有自动化测试断言）；
- **不存储**：不写 localStorage / sessionStorage / cookie（有自动化测试断言）；
- **刷新即清空**：所有内容仅存在于内存中；
- **自定义字体也只在本机读取**，不经过网络。

---

## 公式"潦草化"是怎么做的

数学公式本身无法用 AI 手写模型生成（那些模型只训练过英文手写），所以这里用**渲染后加工**的方式：

1. MathJax 把 LaTeX 渲染成矢量 SVG，保证公式**内容绝对正确**；
2. 把 SVG 栅格化到 2× 超采样的画布上；
3. 按 3px 宽的竖条切片，逐条施加正弦波形位移（模拟手写时笔画被带歪）；
4. 再叠描 2–3 遍，每遍带微小随机偏移与降透明度（模拟来回描画）；
5. 叠加轻微旋转，并按 (公式, 强度, 种子) 缓存，每页只算一次。

这样既保留了公式的数学正确性，又获得了手写的不规则感。

## 已知限制

1. **公式是"印刷体 + 手写扭曲"**，不是真人手写笔迹——这是当前开源方案下"公式正确性"与"手写感"的最佳平衡；
2. 单个公式若宽度超过正文可用宽度，会**自动等比缩小**以完整容纳（不再溢出或裁切）；
3. 中文字体文件较大（约 5–6 MB / 款），首次加载需数秒；
4. 导出 PDF 采用高分辨率位图嵌入，文本不可选中（手写体场景下这是预期行为）；
5. 自定义字体若本身不含中文字形，中文会回退到系统字体显示。
